Pitch is represented by "Pitch" with "hold", "step" and "octave"
Time is represented outside of pitch as "Duration"


The Weakness of the MusicXML approach is it is harder to learn for a beginner as you cannot see what is being changed as you change it. A Strength of MusicXML is the layout as it is very simple.


In the MEI File:
Pitch is represented by "pname", "oct" and "stem.dire"
Time is represented as "dur"


The strengths of this approach is you can see what changes in real time as you adjust the identity of notes, It is also easier to locate code as when you click on a specific note you want to look at, you get brought to that notes code and it is highlighted.
